# Brand kit

## The board

Default: one overview image, 3x3 layout, 4:3 or 16:10, clean gutters,
minimal text. Every board is a visual argument: what the brand
represents, the metaphor, how the logo expresses it, how it scales, and
why it is ownable.

## The 3x3 panel system

1. Logo cover: large mark, strong negative space.
2. Logo construction: grid and geometry, why the mark exists.
3. Digital application: browser, app header, terminal, app icon.
4. Brand essence: one short tagline, large type.
5. Color system: swatches and palette cards.
6. Typography: large specimen, primary and secondary.
7. Physical application: card, badge, packaging.
8. Image direction: cinematic, product crop, material texture.
9. System detail: UI chips, icon row, pattern.

## Brand strategy first

Infer: category, audience, function, emotional promise, trust level,
visual world, metaphor. Symbols are never random. Dev tool: cursor,
frame, bolt. AI: spark, orbit, signal. Security: shield, eye, seal.
Luxury: monogram, emboss. Productivity: path, check, calendar.

## Logo concept (one method, max two)

Monogram with meaning, product action, metaphor fusion, negative space,
construction geometry. The mark must be simple, memorable, scalable,
ownable.

## Visual modes

Dark developer, dark operator, dark nature, dark security, light
editorial, luxury, voice, cultural. Match the mode to the brand.

## Text rules

Very little text: brand name, one tagline, one URL, 2-5 labels. No
paragraphs, no lorem, no menus.

## Anti-generic

No floating icons, generic gradients, fake tiny UI, messy collages,
cheap neon, template boards.
