# Mobile screens

## Platform mode first

Pick one: iOS-native, Android-native, or cross-platform neutral. Never
mix patterns from different platforms.

## The count rule

One screen per image. 1 screen, 1 image. 5 screens, 5 images. Flows:
onboarding, auth with all states, meaningful app sets. Better several
clean screens than one compressed board.

## No cropping

Never crop a screen out of an earlier image. Generate fresh with the
same design language.

## Framing

Default: UI inside a phone mockup with a visible frame. One device
style per set, consistent scale, even margins, the phone never touches
the canvas edge. The mockup supports the screen; the content stays the
hero.

## First screen

One focal point, headline 1-3 lines, no stats or pills, CTA visible.
Respect safe areas, status bar, home indicator, and gesture space.

## Navigation

Familiar patterns: tab bar, stack, sheets, segmented controls. Do not
overload the bottom nav.

## Textured surfaces

Soft film grain, paper texture, frosted feel, tonal fog. Texture
supports the mood and never competes with the text.

## Iconography

A clean custom-feeling system with consistent stroke logic. No Lucide
defaults, no mixed weights.

## Category biases

- Fintech: trust, calm numbers, no chart spam.
- Health: calm, airy.
- Productivity: clarity and discipline.
- Social: rhythm and media moments.
- Commerce: strong product imagery, clean checkout.
- Wellness: soft materials, soft fades.

## Regenerate when

Text too small, crowded, fake navigation, looks like a website, nested
cards, muddy palette, sloppy framing, lost consistency.
