# Imagegen

One job, four modes. Pick the mode from the ask: web references, mobile
screens, brand kit, image to code. Details in references/. house-style
is the law for taste; this file is the craft of image generation.

## The rules that never bend

- One image per section. Never collapse a flow into one collage, never
  crop a section out of a bigger image: generate it fresh.
- Readable text. If the text feels small, the design is not finished.
- One controlled palette per project. Accent logic holds across every
  image.
- One design bible before any multi-image set: palette, type mood,
  spacing, radius, icon style, texture, navigation.
- No purple-blue AI gradients, no generic startup looks, no rainbow.
- No fake names, no filler copy, no meaningless marquees.
- Images are references a coder can recreate, not mood art.
- Mode decides framing: web images horizontal, mobile screens inside
  phone mockups, brand work on boards.

## Mode selection

- Landing page, marketing site, product page: web references
  (references/web.md).
- App concept, onboarding, app screens: mobile (references/mobile.md).
- Logo system, identity deck, brand board: brand kit
  (references/brandkit.md).
- Build a site from generated design: image to code
  (references/image-to-code.md).

## After every set

Run the mode's checklist: count, continuity, palette, readability,
framing, anti-slop. Fix what fails before delivering.

## Origin

Merged from four skills that were one job in four voices:
imagegen-frontend-web, imagegen-frontend-mobile, brandkit, and
image-to-code-skill. Their folders do not come back on sync. Their best
content lives in the references.
