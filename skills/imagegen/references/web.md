# Web references

## The count rule

One separate horizontal image per section. Hero: 1. Landing page: 6.
Full marketing site: 8. Product page or portfolio: 6. Ambiguous:
default high. Announce the count first, then deliver each one labeled
"Section X of N".

## Formats

Horizontal: 16:9, 16:10, or 21:9. Hero usually 16:9 or 21:9. Content
sections 16:10.

## Hero scale (pick one, decisively)

- Giant statement: massive type fills the first viewport.
- Mid editorial: balanced type and image.
- Mini minimalist: tiny logo, short statement, thin CTA, mostly
  negative space. Mini means confidence, not weakness.

## Composition anchors

Pick one per section, at least 3 different anchors across the site,
never the same twice in a row. Left-text-right-image is the overused AI
default: allowed only when it earns it. Before the final layout ask:
"Am I drafting the default out of habit?"

## Background modes

Pick one per section and vary: solid plus asset, texture, full-bleed
image with tonal overlay, editorial side image, image as the visual,
flat block with detail crop, tonal gradient, duotone, radial vignette,
noise gradient. The same mode 3 sections in a row is a reject.

## CTAs

Pick per section from: pill, outline, underlined link with arrow,
full-width banner, oversized headline with tiny hint. Vary at least
once. One unmistakable primary action per viewport.

## Palette

One primary, one secondary, one accent used sparingly, plus neutrals.
Section mood shifts reuse the same palette. Full-bleed images match the
palette tonally. Gradients allowed only as low-chroma tonal grades.

## Second-read moment

Exactly one per page, deliberate: an oversized numeral, a material
switch, a side-rail editorial note. It aids recall, it does not show
off.

## Narrative spine

Pick one and thread it through every section: artifact, journey, tool,
living system, stage, archive.

## Continuity

The same palette, type family and scale, CTA family, radius language,
and image treatment across all sections. Variation only in anchor,
background mode, size, and placement.
