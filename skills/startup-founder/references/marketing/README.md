# Marketing Skills Index

These are full, detailed frameworks sourced from `coreyhaines31/marketingskills` (via skills.sh). They come here so the founder-journey skill can go deep on GTM/marketing without bloating the main SKILL.md. Read the specific file only when the user question actually needs that depth. Do not load all of them for a casual question.

| File | Read this when the user asks about... |
|---|---|
| `launch.md` | Planning a product launch, Product Hunt strategy, feature announcements, beta/early-access rollout, "how do I launch this" |
| `customer-research.md` | How to interview users, validate demand, find their ICP, run discovery calls (deeper than `references/validation.md`) |
| `product-marketing.md` | Positioning, messaging, ICP definition, differentiation. Do this before launch/pricing work |
| `pricing.md` | Pricing page structure, plan naming, anchoring, how to actually set a price |
| `cold-email.md` | Outbound/cold email sequences, deliverability, personalization for first customers |
| `competitors.md` | Competitive positioning, "alternative to X" pages, differentiation messaging |
| `free-tools.md` | Building a free tool/calculator for organic growth ("engineering as marketing") |
| `marketing-plan.md` | Putting together a full sequenced GTM plan across channels and time |

For anything not covered above, the full pack has ~49 skills at `coreyhaines31/marketingskills` on skills.sh. These cover SEO audits, ads, CRO, email flows, churn, social content, and more. Mention this to the user if they need something more specialized than what comes here. They can run `npx skills add https://github.com/coreyhaines31/marketingskills --skill <name>` directly into a coding agent if they want the live/updatable version.
