# Offer worksheet

Fill this with the user, top to bottom. Do not jump to angles before section 1 is done, because angles built on unstated values test nothing.

Keep the filled copy in the repo next to the campaign, not in a chat thread. The next quarter starts from the last scorecard.

## 0. Intake

Ask these five, record the answers, and stop asking.

| Question | Answer |
|---|---|
| Who buys, in one sentence? | |
| What do they buy today instead? | |
| What does the offer cost them, in money and in switching effort? | |
| What is the real reason a buyer says no? | |
| Who runs the sends and who answers replies? | |

The fourth row matters most. Every bucket after this exists to price that objection.

## 1. Four buyer values

Prompt the user with this: what does a buyer get judged on by their boss after they sign? Not what the product does. What shows up in their review, their P&L, or their Monday meeting.

| # | Value | Proof you can show | Strength (1 to 5) |
|---|---|---|---|
| 1 | | | |
| 2 | | | |
| 3 | | | |
| 4 | | | |

Rules:

- Four is the cap. Six values means you have features, not values.
- A value a buyer would not repeat out loud is a feature.
- If two rows say the same thing in different words, cut one.
- Strength is your guess, not data. Section 6 replaces it.

Filled example, commercial waste: price, the same driver every week, an invoice that matches the quote, compliance with state rules backed by an insurance guarantee.

## 2. Three angles, one per value

Each angle becomes a one-line email. Keep the ask identical across all three, or you are testing two things.

```text
{{observation about their world}}.
```

```text
if we could help you {{offer}} without {{risk}}, would that be useful?
```

| # | Angle, in the buyer's words | One-line email | Guess at reply |
|---|---|---|---|
| 1 | | | |
| 2 | | | |
| 3 | | | |

Rules:

- The line names their situation, never your product. If the product name appears, rewrite.
- Lowercase, no greeting, no signature, no tracking pixel.
- One sentence. A second sentence is a second variable.
- No adjectives. "Faster" and "better" are claims the reader discounts.
- Write the ask once, then paste it into all three.

Filled example:

| Angle | Line | Result |
|---|---|---|
| Same driver | "a lot of offices we talk to are walking a new driver through every few weeks." | 5.38% reply, 2.08% interested |
| Invoice matches quote | "we hear a lot about a box rate that turns into a much bigger bill once fuel and fees get added." | 2.10% reply, 1.23% interested |
| Compliance | a free on-site review of where state rules apply | 3.24% reply, 1.12% interested |

## 3. The three-bucket ladder

Take the winning angle from section 2 and keep it fixed. Change only the offer. Two variables at once produce a result you cannot read.

| Bucket | Offer | Your cost per yes | What a yes would prove | Run? |
|---|---|---|---|---|
| 1 | The dream ask, straight into the sales process | | The market wants it at list price | |
| 2 | The same ask plus free work from you | | Free work clears the bar the ask missed | |
| 3 | The ask you hope never converts | | Where friction really sits, and its price | |

Rules:

- Bucket 2 needs a qualifier (section 4), or wrong-fit buyers say yes and waste the sales team.
- Bucket 3 is a falsification test. Price it before you run it, including your cost per yes.
- Stop at bucket 1 when it works. Do not buy friction you do not need.
- Skip to bucket 3 only after 1 and 2 come back flat.

Filled example, against 3-year contracts: meeting (bucket 1), pay 3 months of their current vendor (bucket 2), buy out up to a year of the term (bucket 3). The ladder prices lock-in, which was the real objection.

## 4. The qualifier P.S.

```text
P.S. of course {{the free thing}} is free, to show you we can {{outcome}}.
if we're successful, we'll talk about {{commercial terms}} like the rest of
our customers.
```

Fill it, then answer two questions:

| Check | Answer |
|---|---|
| Who does this line push away? | |
| Is pushing them away correct? | |

If the answer to the second question is no, the offer is wrong, not the P.S. Treat the P.S. as a tested variable, because it changes who replies.

## 5. Run plan

| Bucket | Sends | Start | Subject pattern | Kill if | Keep if |
|---|---|---|---|---|---|
| 1 | 1,000 | | | | |
| 2 | 1,000 | | | | |
| 3 | 1,000 | | | | |

Rules:

- 1,000 sends per sequence before you judge. Below that, you read noise.
- 7 days between buckets on the same pool, with a new subject line. People forget.
- One bucket live at a time. Two live buckets produce one unreadable number.
- Change the subject line between buckets, never inside one.

Read it with this table:

| Result | Meaning | Next move |
|---|---|---|
| Bucket 1 replies | The offer clears cold traffic at full price | Stop testing, run volume |
| Bucket 2 wins | Free work clears the bar | Price the free work, check CAC, then productize |
| Bucket 3 wins | A subsidy does the work | Rebuild 1 and 2 using the gap you found |
| Cash only, all flat | No offer clears cold traffic | Change market or change offer |
| All flat on a clean list | The list or the market is wrong | Re-check the list before touching copy |

Revenue still decides the final winner. Positive replies only tell you which campaign to keep running.

## 7. Before you build anything

- Do not build the lead magnet, the agent, or the team process until a bucket returns replies.
- After a bucket wins, you have 24 to 48 hours to build the thing while the campaign runs.
- If the winning offer needs a process you cannot run at volume, that is a result too. Price it before you promise it.

## Failure modes

- Values that restate the product instead of the buyer's review.
- An angle that names your product.
- Buckets that change the copy and the offer at once.
- Judging after 200 sends, or after one bad week.
- Building the fulfillment before the demand.
- Escalating the offer before an angle wins.
- Writing the P.S. after the send.

## Handoff

Record the filled worksheet with the campaign. At the end of the quarter, re-run section 2 only, against the same four values. Values change slowly. Angles decay fast.
